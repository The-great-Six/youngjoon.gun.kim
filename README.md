# 이영준 일병 게임 모음

이영준 일병과 함께하는 게임 모음입니다. 홈 화면에서 게임을 골라 시작합니다.

| 번호 | 게임 | 상태 |
| --- | --- | --- |
| 게임 1 | 이영준 일병 괴롭히기 | 플레이 가능 |
| 게임 2 | 영준이의 사생활 | 플레이 가능 |

Vite + React + TypeScript 위에 [three.js](https://threejs.org)와 [React Three Fiber](https://r3f.docs.pmnd.rs)를 얹었습니다. 캐릭터는 모델 파일 없이 구, 원기둥, 캡슐 같은 기본 도형을 코드로 조립했고, 효과음은 Web Audio로 냅니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 체크 + 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
```

## 게임 1: 이영준 일병 괴롭히기

- 이영준 일병을 클릭(또는 탭, Enter/Space)하면 **장난 포인트**가 쌓입니다.
- 드래그(또는 좌우 화살표)로 돌려 볼 수 있고, 손을 떼면 잠시 뒤 정면으로 돌아옵니다.
- 도구마다 **급소**가 있습니다. 콕 찌르기는 옆구리, 간지럽히기는 코, 볼 꼬집기는 볼, 딱밤은 이마, 기상나팔은 귀. 급소를 맞히면 포인트가 2배입니다.
- 모자를 치면 삐뚤어지고, 뒤통수를 치면 놀라는 식으로 부위마다 반응이 다릅니다.
- 포인트로 **장난 도구**(간지럽히기, 볼 꼬집기, 딱밤, 기상나팔)를 열면 클릭당 포인트가 커지고 반응도 달라집니다.
- **자동 장난**(모기, 알람, 카톡 폭탄 등)을 사면 가만히 있어도 포인트가 들어옵니다.
- 빠르게 괴롭히면 **짜증 게이지**가 차고, 꽉 차면 이영준 일병이 폭발합니다. 폭발한 6초 동안은 포인트가 3배입니다.
- 한동안 내버려 두면 졸기 시작합니다.
- 진행 상황은 브라우저 `localStorage`에 자동 저장됩니다.

## 게임 2: 영준이의 사생활

영준이가 등을 돌린 사이 관물대를 뒤져 비밀 물건을 모으는 눈치 게임입니다.

- 영준이가 **등을 돌린 동안** 관물대 칸(화면 아래 버튼이나 3D 관물대 문)을 꾹 누르고 있으면 수색 게이지가 찹니다. 키보드는 버튼에 초점을 두고 Space나 Enter를 누르고 있으면 됩니다.
- 영준이가 **낌새를 채면** 곧 돌아봅니다. 돌아봤을 때 누르고 있으면 들키고, 그 칸의 게이지는 처음부터 다시입니다. 세 번 들키면 판이 끝납니다.
- 윗칸은 빨리 열리지만 흔한 물건이 나오고, 아랫칸은 오래 걸리지만 귀한 물건이 나옵니다.
- 물건을 찾을수록 영준이가 예민해져서 더 자주 돌아보고, 돌아보는 척만 하기도 합니다.
- 물건은 20종이고 **일상**, **짝사랑 증거**, **비밀 연애** 세 라인의 도감에 모입니다. 짝사랑과 비밀 연애 라인은 마지막 물건을 찾으면 반전 엔딩이 나옵니다.
- 도감은 브라우저 `localStorage`에 자동 저장됩니다.

물건과 엔딩은 전부 지어낸 것입니다. 실제 인물의 개인 정보(연락처, 가족, 연애, 사진)는 넣지 않습니다.

## 구조

```
src/
├── App.tsx                        # 해시 주소(#/game1)로 홈과 게임을 오간다
├── games.ts                       # 게임 목록. 새 게임은 여기에 한 줄 추가
├── pages/Home.tsx                 # 홈 화면 (게임 카드)
├── shared/
│   ├── youngjoon/Youngjoon.tsx    # 두 게임이 같이 쓰는 3D 이영준 일병 (도형 조립, 표정 8종, 리액션, 부위 판정)
│   ├── youngjoon/types.ts         # 표정, 부위, 리액션 타입
│   └── audio.ts                   # Web Audio 효과음 기본 함수
├── games/poke/                    # 게임 1
│   ├── PokeGame.tsx               # 화면 구성, 클릭 처리, 드래그 회전
│   ├── PokeGame.css               # 레이아웃, 말풍선, 떠오르는 점수
│   ├── components/PokeScene.tsx   # 3D 무대 (캔버스, 조명, 회전)
│   └── game/
│       ├── data.ts                # 도구, 급소, 자동 장난, 대사, 밸런스 수치
│       ├── useGame.ts             # 게임 상태(reducer), 저장/불러오기
│       ├── view.ts                # 회전 상태
│       └── sound.ts               # 효과음
└── games/snoop/                   # 게임 2
    ├── SnoopGame.tsx              # 화면 구성, 꾹 누르기 처리, 도감
    ├── SnoopGame.css              # 레이아웃, 상태 표시, 카드
    ├── components/SnoopScene.tsx  # 3D 무대 (영준이와 관물대)
    └── game/
        ├── items.ts               # 물건 20종, 라인과 엔딩, 칸별 확률, 대사
        ├── useSnoop.ts            # 게임 상태(reducer), 돌아보는 타이밍, 저장/불러오기
        └── sound.ts               # 효과음
```

게임 1의 밸런스나 대사, 급소는 `src/games/poke/game/data.ts`에서, 게임 2의 물건과 엔딩, 확률은 `src/games/snoop/game/items.ts`에서 바꿉니다. 게임마다 따로 지연 로딩하므로 홈 화면은 가볍게 뜹니다.

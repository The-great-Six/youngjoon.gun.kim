# 이영준 일병 괴롭히기

이영준 일병을 클릭으로 괴롭히는 클리커 게임입니다. Vite + React + TypeScript 템플릿만으로 만들었고, 추가 라이브러리는 없습니다. 캐릭터는 SVG로 직접 그렸고 효과음은 Web Audio로 냅니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 체크 + 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
```

## 게임 방법

- 이영준 일병을 클릭(또는 탭, Enter/Space)하면 **장난 포인트**가 쌓입니다.
- 포인트로 **장난 도구**(간지럽히기, 볼 꼬집기, 딱밤, 기상나팔)를 열면 클릭당 포인트가 커지고 반응도 달라집니다.
- **자동 장난**(모기, 알람, 카톡 폭탄 등)을 사면 가만히 있어도 포인트가 들어옵니다.
- 빠르게 괴롭히면 **짜증 게이지**가 차고, 꽉 차면 이영준 일병이 폭발합니다. 폭발한 6초 동안은 포인트가 3배입니다.
- 한동안 내버려 두면 졸기 시작합니다.
- 진행 상황은 브라우저 `localStorage`에 자동 저장됩니다.

## 구조

```
src/
├── App.tsx                  # 화면 구성, 클릭 처리
├── App.css                  # 레이아웃, 애니메이션
├── components/Youngjoon.tsx # 이영준 일병 SVG (표정 8종)
└── game/
    ├── data.ts              # 도구, 자동 장난, 대사, 밸런스 수치
    ├── useGame.ts           # 게임 상태(reducer), 저장/불러오기
    └── sound.ts             # Web Audio 효과음
```

밸런스나 대사를 바꾸려면 `src/game/data.ts`만 고치면 됩니다.
